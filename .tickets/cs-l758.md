# Bare except in _activate_ask silently ignores InputBar query failures

**File**: claude_storm/app.py
**Line(s)**: 208-212
**Description**: The try/except Exception: pass block in _activate_ask silently discards all errors from query_one(InputBar) and set_ask_mode(). If the InputBar fails to enter ask mode due to a real bug, the agent question is displayed in the log but the input bar remains in nudge mode with no error surfaced. The user would not know why their answer is not being routed to the waiting agent.
**Suggested Fix**: Use NoMatches specifically for the non-interactive case. Let other exceptions propagate so genuine errors are visible.
